# LEAN — Let's End Alzheimer's Now

This is a four-page static website for the Northern Valley Demarest LEAN chapter.

## Pages

- `index.html` — Home
- `about.html` — About
- `events.html` — Events and auctions
- `donate.html` — Donation information and official donation link
- `styles.css` — Shared site styles

Open `index.html` in a browser to view the site. The design uses Google Fonts,
Material Symbols, Tailwind's browser stylesheet, and externally hosted images,
so an internet connection is required for the complete appearance.
